# Solomon Tomy Portfolio

## Run Locally
```bash
npm install
npm start
```

## Deploy to GitHub Pages
1. Commit + push code to your repo `portfolio`.
2. Run:
```bash
npm run deploy
```
3. Live at: https://solomontomy.github.io/portfolio

## Replace Avatar
Place your photo in `public/` and update `Hero.js` <img> src.
